Webdesign neu gedacht. 🚀

Wie ich meine erste eigene Webseite minimalistisch, schnell und modern über GitHub Pages aufgebaut habe.

Schritt-für-Schritt Dokumentation

01. GitHub-Konto einrichten

Der Startpunkt für jedes digitale Projekt:

  • Registriere dich kostenlos auf github.com.
  • Erstelle dein Profil und bestätige deine E-Mail-Adresse.

02. Repository erstellen

Lege einen neuen Projektordner an. Wichtig: Das Repository muss auf Public gestellt sein, damit GitHub Pages greift.

03. Struktur & Code aufbauen

Erstelle deine index.html und lagere das Design sauber in einer zentralen style.css aus.

04. Pages aktivieren

Gehe in die Repository-Settings, aktiviere unter Pages den main-Branch – und deine Seite ist live online.
