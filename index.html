Hallo Welt! 🚀

Meine erste eigene Webseite läuft erfolgreich über GitHub Pages.

Ausführliche Dokumentation: Wie ich meine Webseite erstellt habe

Schritt 1: GitHub-Konto erstellen

Der erste Schritt, um Teil der Entwickler-Welt zu werden:

  • Gehe auf github.com.
  • Klicke oben rechts auf Sign up (Registrieren) und folge den Anweisungen, um deinen Account anzulegen. Du brauchst dafür nur eine E-Mail-Adresse und ein Passwort.

Schritt 2: Ein neues Repository (Projekt) erstellen & öffentlich machen

Ein Repository (oder kurz Repo) ist der zentrale Ordner auf GitHub, in dem alle Dateien deiner Webseite liegen.

  • Logge dich bei GitHub ein und klicke oben rechts auf das Plus-Zeichen (+), dann auf New repository.
  • Gib deinem Repository einen Namen (z. B. meine-erste-webseite).
  • Wichtig für GitHub Pages: Das Repository muss als Public (Öffentlich) eingestellt sein, damit die Webseite im Internet für alle erreichbar ist.
  • Falls du es versehentlich auf Privat gestellt hast: Keine Panik! Du kannst das jederzeit ändern, indem du in deinem Repository auf Settings klickst, links unten auf General gehst, ganz nach unten zur Danger Zone scrollst und dort bei Change repository visibility auf Change visibility (Make public) klickst.
  • Setze einen Haken bei Add a README file, damit das Projekt direkt initialisiert wird, und klicke auf Create repository.

Schritt 3: Deine erste HTML-Datei hinzufügen

Damit der Browser weiß, was er anzeigen soll, braucht das Projekt eine Startseite:

  • Klicke in deinem Repository auf den Button Add file und wähle Create new file.
  • Trage oben als Dateinamen exakt index.html ein. (Dieser Name ist essenziell, da GitHub Pages ihn automatisch als Einstiegspunkt erkennt).
  • Füge den HTML-Code ein (so wie diesen hier, der die Seite strukturiert und gestaltet).
  • Klicke rechts oben auf Commit changes... und bestätige das Pop-up, um die Datei abzuspeichern.

Schritt 4: GitHub Pages aktivieren (Die Magie!)

Jetzt muss GitHub nur noch Bescheid geben, dass aus diesen Dateien eine echte Live-Webseite im Netz werden soll:

  • Klicke ganz oben in deinem Repository auf den Reiter Settings (Einstellungen).
  • Scrolle in der linken Menüleiste nach unten zum Bereich Code and automation und klicke auf Pages.
  • Suche nach dem Abschnitt Build and deployment > Branch.
  • Stelle das Dropdown-Menü von None auf main um.
  • Der Ordner daneben bleibt standardmäßig auf / (root).
  • Klicke auf Save.

Nach ein bis zwei Minuten ist deine Seite im Internet erreichbar! GitHub zeigt dir den Link (die URL) direkt ganz oben im Pages-Bereich an.
